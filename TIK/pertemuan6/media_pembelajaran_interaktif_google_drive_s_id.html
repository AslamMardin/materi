Materi A — Google Drive

Penyimpanan berbasis cloud terintegrasi untuk fleksibilitas tinggi.

Google Drive adalah layanan penyimpanan file berbasis cloud (komputasi awan) besutan Google. Layanan ini memungkinkan pengguna menyimpan, mengelola, dan membagikan dokumen secara online tanpa batas perangkat.

Fungsi Utama Google Drive

Menyimpan Dokumen Online
Mencegah kehilangan file akibat kerusakan hardware fisik.
Manajemen File & Folder
Mengelompokkan dokumen agar rapi dan mudah dicari.
Akses Lintas Perangkat
Dapat dibuka dari laptop, tablet, atau smartphone kapan saja.
Membagikan File Praktis
Cukup bagikan tautan tanpa mengirim lampiran fisik berulang.
Kolaborasi Real-time
Bekerja bersama dalam satu dokumen (Docs, Sheets, Slides).

Struktur Folder Administrasi PAI yang Direkomendasikan

Administrasi_PAI/
01_Modul_Ajar/ (RPP, Alur Tujuan Pembelajaran)
02_Jurnal_Mengajar/ (Catatan harian tatap muka)
03_Daftar_Hadir/ (Presensi siswa/mahasiswa)
04_Buku_Nilai/ (Rekapitulasi penilaian tugas & ujian)
05_Materi_Pembelajaran/ (Slide PPT, PDF, Bahan Ajar)
06_Tugas_Mahasiswa/ (Folder pengumpulan berkas)
1. Penamaan Konsisten: Gunakan penomoran di depan folder agar urutan folder selalu tetap dan rapi.
2. Versi Jelas: Hindari nama file seperti "RPP_Final_BGT.docx". Gunakan "RPP_PAI_V1.docx".
3. Cadangan Rutin: Tetap miliki salinan penting secara berkaliber di lebih dari satu tempat.

Materi B — Pemendek URL s.id

Platform pemendek link dan microsite praktis untuk memperluas akses media pembelajaran.

Apa itu Pemendek Tautan (URL Shortener)?

Pemendek URL adalah layanan web yang mengompres tautan panjang (seperti link berbagi Google Drive yang rumit) menjadi bentuk yang jauh lebih ringkas, rapi, dan mudah diingat.

Contoh Praktis Perubahan Link:
https://drive.google.com/file/d/1a2b3c4d5e6f7g8h9i0j_XYZ_PAI_2026/view?usp=sharing
https://s.id/materi-akhlak-pai

Manfaat Utama s.id:

  • Menghemat ruang saat membagikan tautan di WhatsApp atau LMS.
  • Meminimalkan kesalahan pengetikan manual oleh mahasiswa.
  • Memudahkan dosen menulis tautan di slide presentasi / papan tulis.

Kesimpulan & Refleksi Akhir

Rangkuman kunci modul dan rencana implementasi mandiri.

1. Google Drive

Penyimpanan cloud memudahkan mahasiswa dan dosen PAI untuk menyimpan, menata, dan berbagi dokumen dari mana saja secara aman.

2. s.id

Pemendek tautan menjadikan URL bahan ajar yang panjang menjadi ringkas dan mudah diketik tanpa resiko salah karakter.

3. Etika & Keamanan

Penggunaan keduanya wajib diimbangi dengan struktur folder yang teratur, pengecekan izin berbagi, dan kewaspadaan keamanan data.
