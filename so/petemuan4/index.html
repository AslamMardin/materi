Apa itu Process?

Process adalah program yang sedang dieksekusi (in-execution) oleh CPU. Lebih dari sekadar file instruksi, proses mencakup status eksekusi, program counter, register CPU, dan ruang memori (Stack, Heap, Data, Text).

📋 Penjelasan Tahap Transisi State
1
NEW → READY: Proses baru dibuat oleh OS dan dimasukkan ke antrean Ready Queue.
2
READY → RUNNING: CPU Scheduler mengalokasikan giliran CPU kepada proses terdepan.
3
RUNNING → WAITING: Proses memanggil System Call I/O dan diblokir sementara sampai data siap.
4
WAITING → READY: Operasi I/O selesai via Interrupt hardware, proses kembali siap diantrekan.
5
RUNNING → TERMINATED: Proses selesai mengeksekusi instruksi terakhir dan memorinya dibersihkan.

Concurrency & Multithreading

Process & Thread

Proses memiliki ruang alamat memori independen yang terisolasi, sedangkan thread adalah unit eksekusi ringan (Lightweight Process) yang berbagi memori heap dan data di dalam proses yang sama.

⚙️
Process
Program yang sedang berjalan dengan sumber daya yang dikelola OS secara independen. Setiap proses memiliki memori terpisah.
🧵
Thread
Unit eksekusi di dalam proses. Berbagi memori yang sama dengan thread lain dalam satu proses.

✅ Pembahasan
1. Apakah ketiganya merupakan process?
Ya. Setiap aplikasi yang sedang berjalan adalah sebuah process. OS akan membuat PCB unik untuk Chrome, Word, dan VS Code masing-masing.
2. Mengapa ketiganya membutuhkan CPU?
CPU diperlukan untuk mengeksekusi instruksi program. Tanpa CPU, tidak ada kode yang bisa dijalankan. OS mengatur giliran (scheduling) penggunaan CPU antar proses.
3. Mengapa ketiganya membutuhkan RAM?
RAM menyimpan data dan instruksi yang sedang aktif digunakan oleh proses. Semakin banyak proses berjalan, semakin banyak RAM yang digunakan.
4. Siapa yang mengelola CPU dan RAM?
Kernel (inti OS) bertugas mengatur alokasi CPU (process scheduling) dan RAM (memory management) untuk seluruh proses yang berjalan.
5. Terlalu banyak proses?
Kinerja turun drastis karena: RAM bisa penuh (swapping ke disk), CPU harus berbagi ke banyak proses (context switch berlebihan), dan sistem menjadi lambat atau hang.
