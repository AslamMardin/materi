Materi Inti

Pengertian Sistem Operasi (Operating System)

Sistem Operasi adalah perangkat lunak sistem (system software) yang mengelola sumber daya perangkat keras komputer, menyediakan layanan umum untuk aplikasi, dan bertindak sebagai perantara krusial.

"Tanpa sistem operasi, perangkat keras hanyalah tumpukan komponen elektronik tanpa daya guna."

Contoh Sistem Operasi Populer

Windows (PC/Kerja)
Linux (Server/Desktop)
macOS (Mac Computer)
Android & iOS (Mobile)
OS memastikan efisiensi, keamanan, dan kemudahan interaksi manusia dengan mesin.

Analisis Tujuan

Tujuan Utama Sistem Operasi

Memudahkan Pengguna

Menyediakan antarmuka (GUI/CLI) sehingga manusia dapat mengoperasikan komputer tanpa harus menulis bahasa mesin yang rumit.

Mengelola Sumber Daya Efisien

Mengatur alokasi CPU, memori, dan perangkat I/O secara adil dan optimal agar performa komputer tetap terjaga.

Lingkungan Eksekusi Aplikasi

Menyediakan pustaka layanan dan standar bagi programmer untuk merancang aplikasi yang dapat berjalan lintas perangkat.

Keamanan dan Kestabilan

Melindungi data pengguna, mengatur hak akses, dan mencegah satu aplikasi error yang merusak keseluruhan sistem.

Tujuan ini menjadikan komputer alat bantu produktivitas yang handal.
Manajemen Sumber Daya (1)

Fungsi Manajemen Proses

Konsep Penjadwalan CPU

Sistem operasi mengatur jalannya program (proses). CPU dibagi waktunya dengan sangat cepat (time-sharing) sehingga seolah-olah puluhan aplikasi berjalan bersamaan.

Status Proses: Ready, Running, Waiting / Blocked, Terminated.

Contoh Aktivitas Mahasiswa

Saat mahasiswa membuka Browser (untuk tugas kuliah), Microsoft Word (mengetik laporan), dan Pemutar Musik secara bersamaan:

  • OS mengatur giliran CPU untuk melayani ketiga aplikasi tersebut secara bergantian dalam hitungan milidetik.
  • Mencegah satu aplikasi memonopoli sumber daya prosesor.
Manajemen proses memastikan multitasking berjalan mulus tanpa macet total.
Manajemen Sumber Daya (2)

Fungsi Manajemen Memori

Peran RAM Utama

Memori utama (RAM) adalah sumber daya kritis tempat data dan instruksi program dimuat sebelum dieksekusi CPU.

  • Alokasi dan pelepasan memori saat aplikasi dibuka atau ditutup.
  • Melindungi ruang memori antar aplikasi agar tidak saling tumpang tindih.

Dampak Keterbatasan RAM

Ketika RAM hampir habis, OS menggunakan teknik Virtual Memory (Swap space pada SSD/HDD).

Akibat: Kinerja komputer menjadi sangat lambat (lagging) karena proses baca-tulis media penyimpanan jauh lebih lambat dibanding RAM fisik.
Pengelolaan memori yang baik memaksimalkan stabilitas eksekusi program.
Manajemen Sumber Daya (3)

Manajemen File dan Penyimpanan

Tugas Sistem Berkas (File System)

  • Pembuatan, penghapusan, pembacaan, dan penulisan file.
  • Pengorganisasian direktori dan folder hierarkis.
  • Pengaturan hak akses file (read, write, execute).
  • Abstraksi perangkat fisik penyimpanan (SSD/HDD/Flashdisk).

Contoh Struktur Folder Kuliah

📁 Semester2/

│ ├── 📄 Materi_Pertemuan2.pdf
│ └── 📁 TugasKlp/
└── 📁 PemrogramanWeb/
Memastikan data tersimpan terstruktur, aman, dan mudah diakses kembali.
Manajemen Sumber Daya (4)

Manajemen Perangkat Input / Output (I/O)

Input Devices

Mengelola sinyal dari keyboard, mouse, mikrofon, dan sensor agar dapat dipahami oleh sistem.

Output & Storage

Mengontrol monitor, printer, speaker, serta media eksternal melalui mekanisme antarmuka standar.

Device Driver

OS menggunakan perangkat lunak perantara (driver) untuk berkomunikasi langsung dengan berbagai merek perangkat keras.

Pengguna cukup mencolokkan perangkat tanpa pusing memikirkan protokol sirkuit elektronik.
Integritas Sistem

Keamanan, Proteksi, dan Pembaruan Sistem

Mekanisme Proteksi OS

  • Akun Pengguna & Autentikasi: Pemisahan hak akses antar user (Admin vs Regular User).
  • Perlindungan Memori: Mencegah aplikasi liar mengakses data aplikasi lain.
  • Pembaruan Sistem: Menambal celah keamanan (security patch).

Catatan Akademik Penting

Jangan menyamakan Sistem Operasi dengan Antivirus!

Sistem operasi menyediakan fondasi proteksi dan kontrol akses secara menyeluruh, sedangkan antivirus adalah aplikasi tambahan pihak ketiga yang khusus memindai ancaman malware.

Integritas sistem menjaga kerahasiaan dan ketersediaan data pengguna.
Klasifikasi OS

Jenis dan Contoh Sistem Operasi

Windows

Dominan pada komputer pribadi (PC), laptop kerja, dan gaming. Antarmuka intuitif dan dukungan aplikasi luas.

Linux

Standar industri untuk server web, superkomputer, cloud, serta sistem tertanam (embedded systems).

macOS

Sistem operasi eksklusif untuk jajaran komputer Mac buatan Apple dengan stabilitas tinggi dan desain elegan.

Android

Sistem operasi berbasis Linux untuk perangkat seluler cerdas, tablet, dan perangkat sandang.

iOS

Sistem operasi seluler tertutup yang sangat teroptimasi khusus untuk perangkat iPhone dan iPad.

Setiap OS memiliki karakteristik arsitektur dan ekosistem tersendiri.
Studi Kasus Analisis

Analisis Permasalahan Kinerja Komputer

Skenario Masalah

Sebuah laptop mahasiswa terasa sangat lambat (lagging) ketika browser dibuka dengan 30 tab aktif, aplikasi presentasi berjalan, dan beberapa program musik beroperasi di latar belakang.

Diskusikan dengan teman sebangku sebelum membuka pembahasan.
1. Fungsi Terkait: Manajemen Memori & Manajemen Proses.
2. Sumber Terbebani: RAM utama habis, memicu penggunaan Virtual Memory (Swap) pada SSD/HDD.
3. Pemeriksaan: Buka Task Manager / Activity Monitor untuk melihat persentase penggunaan RAM & CPU.
4. Solusi: Tutup tab browser yang tidak perlu atau tambah kapasitas RAM fisik.
Menerapkan konsep dasar OS untuk troubleshooting praktis.
